# Hermes for T3 Code — production expansion

## Style block

- Mood: technical broadside, open-source release receipt, confident without hype.
- Canvas: `#000000`; primary type: `#FFFFFF`; action accent: `#0055FF`; proof marker: `#20C55A`.
- Display: `-apple-system`, weight 800–900, tight tracking; chrome: `IBM Plex Mono`, uppercase, tracked.
- Surfaces are flat and square with hairline structure. No shadows, rounded cards, multicolor gradients, fake UI, or invented metrics.

## Rhythm

`HOOK — build — BUILD — PROOF — hold`

Thirty-five seconds across five frames. The mechanism grows from one outcome statement into a three-station map, accelerates through the three usable flows, peaks on verified metrics, and exhales into a public-source invitation.

## Global motion rules

- Every frame has one dominant display moment, two to four supporting structural roles, and one seek-safe ambient motion.
- Entrances vary between type stamping, lateral station travel, panel cascade, number count-up, and terminal typing.
- Use zoom-through once at the mechanism reveal, push-slide for the continuing flow sequence, squeeze for the proof reset, and blur-crossfade into the final hold.
- Every reveal lands when its matching phrase is spoken; no frame dumps all content in its first second.

## Frame beats

### 01 — One cockpit

Concept: terminal-only orchestration feels invisible; one visible cockpit resolves that friction. Large type behaves like a protest poster, with “One cockpit” as the first blue declaration.

Depth: black field, faint terminal-rule texture, oversized ghost prompt, white tension line, blue outcome line, mono release label, green ready marker.

Choreography: tension STAMPS, “terminal” wipes, the blue promise CRASHES into the cleared field, the proof marker PULSES once.

### 02 — Both directions

Concept: a camera traverses T3 Code → bridge → Hermes, then a second path travels back. The world is one technical map with no forked product clones.

Depth: three stations, top/bottom chrome, twin directional lines, moving packet dots, state labels, oversized background arrow.

Choreography: stations SLIDE into registered positions, camera PANS, the outbound path DRAWS, the return path SNAPS back, labels SETTLE.

### 03 — Three live flows

Concept: “bidirectional” becomes three concrete actions. The final @hermes panel stays linked and visibly continues.

Depth: three asymmetrical panels, flow indices, bright arrows, typed mention, linked-thread rail, mono state receipts.

Choreography: panels CASCADE one at a time, arrows DRAW in alternating directions, @hermes TYPES, linked state CHECKS on.

### 04 — Proof before promotion

Concept: a dense evidence wall answers skepticism. Every number is already verified by the release record.

Depth: four metric zones, hairline axes, large numeric type, micro labels, security correction trail, green release marker.

Choreography: numerals COUNT UP or snap to their exact values, labels ARRIVE on separate cadences, security findings CROSS OUT into fixed states, release marker PULSES.

### 05 — The receipt is public

Concept: founder intent and AI execution become a public artifact. The invitation ends on source, not self-congratulation.

Depth: four-step receipt, typed repository URL, thumbnail bridge treatment, open-source/MIT chrome, contribution CTA.

Choreography: receipt lines STAMP in, command TYPES, poster REVEALS from a masked edge, URL HOLDS, blue bidirectional line BREATHES through the final frame.

## Recurring motifs

- Bidirectional arrow pair.
- Catalogue numbers and proof receipts.
- One green marker only when a gate has genuinely passed.
- Blue as the sole action color; white and near-black carry the system.

## Negative prompt

No endorsements, partner logos, private T3 threads, secrets, fake testimonials, unverified claims, terminal-green hacker clichés, purple cyberpunk gradients, glassmorphism, rounded dashboard cards, or generic robot imagery.
